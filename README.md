# Life Coach AI 项目

## 项目简介
这是一个基于DeepSeek R1 API开发的个人成长辅导网站。通过与AI进行对话，用户可以获得个性化的建议和指导，帮助个人成长。

## 技术架构
- 前端：HTML5 + CSS3（响应式设计）
- 后端：Node.js
- AI接口：火山方舟 DeepSeek R1 API

## 页面结构

### 主页面 (index.html)
- 页面布局：采用Flexbox布局
- 主要组件：
  - 顶部导航栏：显示网站标题
  - 聊天界面：
    - 消息显示区域（占据主要空间）
    - 输入框区域（底部固定）
  - 响应式设计：适配桌面和移动设备

### 样式设计
- 配色方案：
  - 主色调：#4A90E2（平静的蓝色）
  - 背景色：#F5F8FA（浅灰色背景）
  - 文字颜色：#333333（深灰色）
- 字体：
  - 中文：系统默认字体
  - 英文：Arial, sans-serif

## 功能特性
1. 实时对话：支持与AI助手进行实时对话
2. 上下文记忆：保持对话的连贯性
3. 响应式设计：适配各种屏幕尺寸
4. 流式输出：实时显示AI回复

## 开发规范
- 使用语义化HTML标签
- CSS采用BEM命名规范
- 代码添加中文注释
- 遵循W3C标准

- 使用CSS压缩

- 添加适当的加载状态提示
